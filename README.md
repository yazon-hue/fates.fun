# Fates — pitch deck

Pitch deck for **Fates ($FATES)**: parlays on Elysium, Hyperliquid's first L2. Players stack 2–5 coin price targets into one ticket; a house vault of HYPE/USDC takes the other side, and token stakers own the house.

A single-file web deck. Navigate with arrow keys, scroll, swipe, or the on-screen arrows. Add `#11` to the URL to open a specific slide (slide 11 is the revenue scenarios). On a phone it reads best in landscape.

## Deploy to GitHub Pages

1. In the repo, go to **Settings → Pages**.
2. Set **Source** to **Deploy from a branch**, then choose `main` and `/ (root)`, and save.
3. The deck will be live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.

## Notes

- All slides live in `index.html`; edit the text in place, no build step.
- Revenue figures are illustrative scenarios, not forecasts. The legs.fun fee figure is an estimate.
- The editable version of this deck lives in Claude; this file is an export of it.
